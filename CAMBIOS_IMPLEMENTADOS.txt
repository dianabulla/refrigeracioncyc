3️⃣  FUNCIONES DE SEGURIDAD (config/session_security.php)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Funciones de Lectura:
  ├─ getSessionContext(): array
  │   └─ Retorna todo (usuario_id, empresa, finca, rol, tipo)
  │
  ├─ getSessionEmpresa(): string|null
  │   └─ Retorna empresa (null = superusuario)
  │
  └─ getSessionFinca(): string|null
      └─ Retorna finca (null = superusuario)


Funciones de Validación:
  ├─ canAccessEmpresa($empresa): bool
  │   └─ ¿El usuario puede acceder a esta empresa?
  │
  ├─ canAccessFinca($finca): bool
  │   └─ ¿El usuario puede acceder a esta finca?
  │
  ├─ canAccessEmpresaFinca($empresa, $finca): bool
  │   └─ ¿El usuario puede acceder a empresa Y finca?
  │
  └─ canAccessRecord($pdo, $tabla, $id): bool
      └─ ¿El usuario puede acceder a este registro?


Funciones de Query:
  └─ buildSecureQuery($sql, $alias, $filtroE, $filtroF): array
      └─ Retorna ['query' => '...', 'params' => [...]]
      └─ Agrega filtros WHERE automáticos


Funciones de Auditoría:
  └─ auditarAcceso($pdo, $accion, $tabla, $id, $anterior, $nuevo): void
      └─ Registra cambios en auditoria_acceso


Funciones Requeridas (lanzan error):
  ├─ requireSessionContext(): void
  │   └─ Valida que existe sesión completa
  │
  ├─ requireAccessEmpresa($empresa): void
  │   └─ Valida acceso a empresa (403 si falla)
  │
  ├─ requireAccessFinca($finca): void
  │   └─ Valida acceso a finca (403 si falla)
  │
  └─ requireAccessEmpresaFinca($empresa, $finca): void
      └─ Valida ambas (403 si falla)
