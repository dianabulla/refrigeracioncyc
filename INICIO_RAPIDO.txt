⚙️ FUNCIONES DISPONIBLES
═════════════════════════════════════════════════════════════════════════════════

Datos de Sesión:
  getSessionContext()          → Todo (empresa, finca, usuario, rol)
  getSessionEmpresa()          → Solo empresa
  getSessionFinca()            → Solo finca

Validación:
  canAccessEmpresa($empresa)   → true/false
  canAccessFinca($finca)       → true/false
  canAccessRecord($pdo, $tabla, $id)  → true/false

Queries:
  buildSecureQuery($sql, $alias, $filterEmpresa, $filterFinca)
  → Retorna ['query' => '...', 'params' => [...]]

Auditoría:
  auditarAcceso($pdo, $accion, $tabla, $id, $anterior, $nuevo)

Validación Requerida (lanza error):
  requireAuth()
  requireSessionContext()
  requireAccessEmpresa($empresa)
  requireAccessFinca($finca)


❌ ERRORES A EVITAR
═════════════════════════════════════════════════════════════════════════════════

❌ SELECT * FROM tabla
   Sin filtrar empresa/finca

✅ SELECT * FROM tabla 
   WHERE empresa = :e AND finca = :f

───────────────────────────────────────────────────────────────────────

❌ if ($_GET['empresa'] == 'A')
   Confiar en parámetro del usuario

✅ $empresa = getSessionEmpresa()
   Obtener del servidor

───────────────────────────────────────────────────────────────────────

❌ WHERE id = " . $_GET['id']
   SQL Injection

✅ WHERE id = ? [usando prepared statements]
   Seguro contra SQL Injection

───────────────────────────────────────────────────────────────────────

❌ UPDATE usuario SET codigo_empresa = ?
   Permitir que usuario cambie su empresa

✅ No permitir cambios de empresa/finca por usuario
   Solo administradores pueden hacer esto


📞 REFERENCIAS RÁPIDAS
═════════════════════════════════════════════════════════════════════════════════

¿Cómo obtengo la empresa del usuario actual?
→ $ctx = getSessionContext();
→ echo $ctx['codigo_empresa'];

¿Cómo agrego filtros a una query?
→ $result = buildSecureQuery($sql, 'alias', true, true);
→ $stmt = $pdo->prepare($result['query']);
→ $stmt->execute($result['params']);

¿Cómo valido que un usuario puede acceder a un registro?
→ if (!canAccessRecord($pdo, 'reporte', $recordId)) {
→     respond(['error' => 'Forbidden'], 403);
→ }

¿Cómo registro cambios en auditoría?
→ auditarAcceso($pdo, 'UPDATE', 'reporte', $id, $anterior, $nuevo);

¿Cómo valido la sesión?
→ requireSessionContext();  // Lanza error si falta

¿Los superusuarios ven todo?
→ Sí, getSessionEmpresa() retorna null para ellos (no filtra)

¿Qué pasa si un usuario intenta cambiar ?id en URL?
→ canAccessRecord() retorna false → Error 403 Forbidden
